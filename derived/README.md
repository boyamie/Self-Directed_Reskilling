# derived/

Generated by `make aggregate` and `make export`. Committed on purpose: the
paper cites a state of this directory, and a reviewer should be able to see
the numbers without running anything.

Do not hand-edit. `principle4.json` in particular is the output of
`tools/calog.py decide()`, which implements `PROTOCOL.md` §2.1 — if the
verdict looks wrong, the argument is with the protocol or the logs, not with
this file.

`ots/` holds OpenTimestamps proofs written by the post-commit hook.
