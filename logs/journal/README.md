# Work journal

One file per day, `YYYY-MM-DD.md`. Free text. Log hours, tasks, decisions,
affect, obstacles. This is a data source for the paper, not a diary for
publication — write it as if a reviewer will read excerpts, because one will.

Suggested opening line each day: `hours: 1.5 | track: learning|market|assets`
so `tools/calog.py aggregate` can total hours per track.
